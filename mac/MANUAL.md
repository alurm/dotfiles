## Install Maple Mono

Normal, without ligatures, with nerd symbols, also known as "MapleMonoNormalNL-NF" or "Maple Mono Normal NL NF".

## Configure Firefox

- Set `browser.tabs.insertAfterCurrent` to true to make new tabs appear after the current one.
- Set `browser.link.open_newwindow` to 1 to force links to open in the current tab. (https://support.mozilla.org/en-US/questions/1190923)
- Set `browser.tabs.closeWindowWithLastTab` to false.
- Set `browser.compactmode.show` to true and enable compact mode.
